# 📊 Gestión de Afiliaciones - Web
Sistema administrativo desarrollado en **PHP** y **MySQL** para el control de afiliaciones, renovaciones y cálculos de ganancias logísticas.

## 🚀 Funcionalidades
- Registro y consulta de afiliados.
- Gestión de pagos y renovaciones.
- Módulos de seguridad y control de acceso.
- Interfaz optimizada para gestión local.

## 🛠️ Tecnologías utilizadas
- **Backend:** PHP
- **Base de Datos:** MySQL
- **Frontend:** HTML, CSS, JavaScript
